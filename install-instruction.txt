Here is the short, clean, step-by-step guide you can share with the other Change Manager:

1. Clone the project: Open your Terminal and run:
git clone https://gitlab.gosystem.io/ci/change-manager-assistant.git
cd change-manager-assistant

2. Set up Python Environment: Create and activate a clean virtual workspace:
python3 -m venv venv
source venv/bin/activate

3. Install libraries: Use pip3 to explicitly install all required dependencies directly inside your active workspace folder:
pip3 install -r requirements.txt
(Wait 30–60 seconds for the installation bars to finish completely).

4. Create the .env configuration file: Create a new file named exactly .env in the project folder. Open it in a text editor and add your Jira access keys:
JIRA_SERVER="https://jira.gosystem.io"
JIRA_API_TOKEN="your_personal_jira_token_here"

5. Start the Backend server: In your current terminal window, launch the core processing engine:
python3 main.py
(Keep this terminal open and running in the background).

6. Start the Frontend UI: Open a brand new terminal window, navigate back to the folder, activate the environment, and bypass shell restrictions by running Streamlit directly through Python:
cd change-manager-assistant
source venv/bin/activate
python3 -m streamlit run app.py

The application will automatically open in your web browser at
http://localhost:8501 and is ready to use!






Here are the short steps for how to push code updates to GitLab whenever you make changes to your files:

1. Check your changes: Open your terminal in the project folder and see what files you modified:
Bash
git status

2. Stage the updates: Add the files you want to save (replace app.py with whatever file you changed):
Bash
git add app.py(Or run 
git add . to stage all modified files at once).

3. Commit the changes: Write a short note explaining what you updated:
Bash
git commit -m "Fix layout bug on analytics dashboard"

4. Push to GitLab: Send your committed changes up to the repository branch:
Bash
git push origin main
